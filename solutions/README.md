# Solutions Workspace

Use this folder for your own implementations while keeping the course materials unchanged.

## Suggested Layout

- `labs/` for the five main labs and the final project
- `optional-exercises/` for extra practice work

## Naming Suggestion

- `labs/lab01-url-shortener/`
- `labs/lab02-code-analyzer/`
- `labs/lab03-migration-workflow/`
- `labs/lab04-rag-system/`
- `labs/lab05-multi-agent/`
- `labs/final-project/`

Inside each project, keep its own README, source code, environment files, and deployment notes.
