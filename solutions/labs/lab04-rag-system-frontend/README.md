# Lab 04 RAG System Frontend

Static frontend for Vercel.

## Files

- `index.html`
- `styles.css`
- `script.js`
- `config.js`
- `vercel.json`

## What It Shows

- indexing code files
- grounded query answers
- retrieved source snippets
- evaluation metrics
- per-example judge scores

## Local Use

1. Set the backend URL in `config.js`
2. Open `index.html` directly, or run:

```bash
python3 -m http.server 4173
```

## Vercel

Use this folder as the Vercel project root:

```text
solutions/labs/lab04-rag-system-frontend
```
